# Shared Expense Manager
A full-stack web app to manage shared expenses among multiple users.

## Features
1. ADD MEMBERS
2. ADD EXPENSES
3. STORE DATA IN MONGODB ATLAS
4. VIEW EXPENSE HISTORY
5. DATA PERSISTS AFTER PAGE REFRESH

## Tech Stacks
1. HTML
2. CSS
3. JavaScript
4. Node.js
5. Express.js
6. MongoDB Atlas
7. Mongoose
